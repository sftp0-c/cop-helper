# ЦОП Помощник

Firefox WebExtension для Цифровой образовательной платформы ХМАО — Югры. Версия 3.0 превращает помощник в заметную панель, встроенную непосредственно в страницу ЦОП.

## Версия 3.0.0

- Плавающая кнопка «ЦОП Помощник» и боковая панель с поиском и навигацией.
- Контекстная подсказка по текущему разделу портала (электронный журнал, ПФДО, питание, поддержка).
- Поиск по сценариям и популярным действиям.
- Пошаговый режим с отметками выполнения и индикатором прогресса.
- Подсветка найденных надписей и ближайших кнопок/ссылок. Помощник ничего не нажимает за пользователя.
- Избранные инструкции, история последних 30 запросов.
- Компактный режим и светлая/тёмная тема.
- Изоляция интерфейса в Shadow DOM, чтобы стили ЦОП не ломали панель и стили помощника не меняли оформление сайта.
- **Content script запускается только на `https://cop.admhmao.ru/*`.** На портале ПФДО, подсистеме питания и любых других сайтах кнопка помощника не появляется. Ссылки на внешние ресурсы открываются отдельно.
- Избранное, история, настройки и прогресс хранятся локально в браузере.

## Установка в Firefox

1. Скачайте ZIP-архив ветки или репозитория и распакуйте его.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите **Load Temporary Add-on** и выберите `manifest.json`.
4. Откройте или обновите страницу ЦОП: [https://cop.admhmao.ru/elk](https://cop.admhmao.ru/elk).
5. В правом нижнем углу появится кнопка **ЦОП Помощник**.

Временное дополнение может потребовать повторной загрузки после перезапуска Firefox. Для постоянной установки нужна публикация/подписание расширения по правилам Mozilla.

## Поддерживаемые сценарии

- ЭЖД: родитель, ученик, учитель.
- Переход родителя в ПФДО.
- Назначение онлайн-урока учителем (по официальной инструкции ЦОП; названия элементов могут измениться).
- Назначение/подтверждение питания (демонстрационный маршрут, требует актуальной инструкции).
- Подбор школы или детского сада.
- Обращение в службу поддержки.

## Достоверность инструкций и ограничения

Маршруты ПФДО и онлайн-уроков сверялись с опубликованными руководствами ЦОП, но документы не новые и интерфейс портала мог измениться. Маршрут питания требует актуальной инструкции. Перед практическим использованием сверяйте шаги с текущим интерфейсом и локальными правилами организации.

При подготовке предыдущей версии портал ЦОП вернул HTTP 502, поэтому живую проверку всех экранов выполнить не удалось. До выпуска для пользователей рекомендуется пройти контрольные маршруты в разрешённой тестовой среде.

Расширение не обходит авторизацию, не получает пароли и коды ЕСИА, не нажимает кнопки подтверждения и не выполняет операции от имени пользователя. Не вводите в помощник пароли, коды подтверждения и другие секретные данные.

## Структура

| Файл | Назначение |
|---|---|
| `manifest.json` | Firefox MV3, разрешение только для домена ЦОП и локальное хранилище |
| `data.js` | Локальная база маршрутов и поиск |
| `popup.html`, `popup.js` | Окно расширения в панели Firefox |
| `content.js` | Кнопка, встроенная панель, контекстные подсказки, избранное и пошаговый режим |
| `icon.svg` | Иконка |
| `docs/tz.txt` | Исходное ТЗ |

## Проверки

В каталоге проекта:

```bash
node --check data.js
node --check popup.js
node --check content.js
node tests/search.test.cjs
```

Затем проверить вручную в Firefox:
- наличие кнопки только на `cop.admhmao.ru`;
- отсутствие кнопки на `hmao.pfdo.ru`, `cop-pitanie.admhmao.ru` и любых посторонних сайтах;
- поиск, уточнение неоднозначного запроса и неизвестный запрос;
- контекстные подсказки для разных разделов;
- пошаговый прогресс, сохранение отметок после перезагрузки;
- добавление/удаление избранного, историю и её очистку;
- подсветку текста и восстановление исходного оформления страницы;
- компактный режим и переключение темы.
