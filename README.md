# ЦОП Помощник

Firefox WebExtension для навигации по Цифровой образовательной платформе ХМАО — Югры. Расширение работает локально в браузере: ищет подходящий маршрут, показывает последовательность действий, открывает известные разделы и подсвечивает найденный текст/интерактивный элемент на текущей странице.

## Версия 2.0.0

- Переработан поиск: нормализация русских запросов, синонимы, учет роли и уточнение неоднозначных запросов.
- Для каждого сценария отображаются роль, стартовый экран, ожидаемый результат и статус достоверности.
- Сценарий онлайн-урока обновлён по официальным руководствам ЦОП; маршрут питания помечен как требующий сверки, поскольку подтверждённая пошаговая инструкция не найдена.
- Переработаны popup и панель на странице, контрольные маршруты и локальный журнал последних 30 запросов.
- Подсветка ищет видимый текст и выделяет ближайшую кнопку/ссылку, если она содержит совпадение. Подсветка не нажимает элементы и не отправляет формы.
- Ограничены домены, на которых запускается content script: ЦОП, портал ПФДО и подсистема питания. Больше нет доступа ко всем сайтам.
- Запросы и история хранятся в локальном хранилище браузера. Никакие запросы не отправляются на сервер расширения.

## Установка в Firefox

1. Скачайте репозиторий и распакуйте архив.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите **Load Temporary Add-on** и выберите `manifest.json`.
4. Откройте или обновите страницу ЦОП: `https://cop.admhmao.ru/elk`.
5. Нажмите кнопку **Помощник** в правом нижнем углу или откройте расширение через панель Firefox.

Для временной установки после перезапуска Firefox может потребоваться загрузить дополнение повторно. Для постоянной установки нужна публикация/подписание расширения по правилам Mozilla.

## Поддерживаемые сценарии

- ЭЖД: родитель, ученик, учитель.
- Переход родителя в ПФДО.
- Назначение онлайн-урока учителем (по официальной инструкции ЦОП; перед применением сверяйте интерфейс с текущей версией).
- Назначение/подтверждение питания (демонстрационный маршрут, требует проверки актуальной инструкции).
- Подбор школы или детского сада.
- Обращение в службу поддержки.

## Важные ограничения и достоверность

ТЗ требует связывать маршруты с актуальными инструкциями, скриншотами и разрешёнными ссылками, а также отдельно учитывать роль и начальный экран. В текущей версии ссылки и некоторые названия действий унаследованы из исходной конфигурации проекта и публичных материалов. Интерфейс ЦОП может изменяться; если маршрут помечен как требующий сверки, не используйте его как пошаговую официальную инструкцию.

Открытие сайта ЦОП в среде разработки при подготовке версии 2.0.0 завершилось ошибкой HTTP 502, поэтому живую проверку всех экранов выполнить не удалось. При этом онлайн-уроки и ПФДО сверены с опубликованными официальными руководствами ЦОП (PDF), но эти документы не новые и интерфейс мог измениться. До выпуска для пользователей необходимо пройти контрольные маршруты в тестовой/разрешённой среде и добавить актуальные скриншоты. По питанию нужна отдельная актуальная инструкция.

Расширение не обходит авторизацию, не получает пароли/коды ЕСИА, не нажимает кнопки подтверждения и не выполняет операции от имени пользователя. Передача вопросов специалисту должна использовать только контакты, опубликованные на официальной странице поддержки.

## Структура

| Файл | Назначение |
|---|---|
| `manifest.json` | Firefox MV3, ограниченные домены и разрешения |
| `data.js` | Локальная база маршрутов и поиск |
| `popup.html`, `popup.js` | Окно расширения |
| `content.js` | Панель на странице и подсветка |
| `icon.svg` | Иконка |
| `docs/tz.txt` | Исходное ТЗ |

## Проверки перед релизом

В каталоге проекта:

```bash
node --check data.js
node --check popup.js
node --check content.js
```

Затем проверить вручную в Firefox:
- поиск родительского, ученического и учительского маршрутов;
- неоднозначные запросы и неизвестный запрос;
- переходы по ссылкам;
- подсветку слова, подсветку кнопки/ссылки, снятие подсветки;
- журнал и очистку журнала;
- отсутствие кнопки помощника на посторонних сайтах;
- контрольные маршруты на разрешённом тестовом интерфейсе.
