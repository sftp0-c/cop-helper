# ЦОП Помощник

Расширение для Firefox: помощник по ЦОП ХМАО – Югры. По вопросу пользователя
находит нужный маршрут, показывает проверенную последовательность действий,
открывает разрешённые разделы и подсвечивает слова на странице.

## Возможности

- Поиск по 8 типовым маршрутам из ТЗ (ПФДО, ЭЖД для родителя/ученика/учителя,
  онлайн-уроки, питание, выбор школы/детсада, служба поддержки).
- Для маршрута показываются: роль, стартовый экран, ожидаемый результат, шаги
  и разрешённые ссылки.
- **Подсветка самих слов**: найденные слова оборачиваются в `<mark>` — жёлтый
  фон, чёрный жирный текст, красная обводка; контейнер обводится рамкой.
- **Прямое поле «Слово на странице»** — можно подсветить любое слово вручную
  (например, `ПФДО`). Есть счётчик «Найдено совпадений: N», кнопки
  «Обновить подсветку» и «Снять подсветку».
- Уточнение запроса, сообщение о недоступном разделе и передача вопроса
  специалисту (`cophelp@admhmao.ru`, `8 800 100-58-67`).
- «Контрольные маршруты» и «Журнал ответов» (последние 20 запросов).

## Запуск

**Основной способ — кнопка на сайте.** После установки в правом нижнем углу
любой страницы появляется жёлтая кнопка **«🔍 Помощник»**. Она открывает большую
панель с поиском и подсветкой прямо на странице — не нужно открывать меню
расширения. Иконка в панели Firefox тоже работает.

Установка для разработки:

1. Откройте `about:debugging#/runtime/this-firefox`.
2. «Load Temporary Add-on» → выберите `manifest.json` из этой папки.
3. **Обновите вкладку сайта** — старый content script иначе останется в странице.

## Структура

| Файл | Назначение |
|---|---|
| `manifest.json` | Манифест Firefox (MV3), подключает `data.js` и `content.js` |
| `data.js` | База маршрутов и поиск (используется и в popup, и на странице) |
| `popup.html`, `popup.js` | Окно помощника в панели Firefox |
| `content.js` | Кнопка-помощник на сайте, панель поиска, подсветка слов |
| `icon.svg` | Иконка расширения |
| `docs/tz.txt` | Исходное техническое задание |

## Источники данных

- ТЗ: `docs/tz.txt`.
- Ссылки и часть кнопок (`Перейти`, `Подобрать`, `Система Электронного
  журнала`, `Служба поддержки`) — с реального сайта `https://cop.admhmao.ru`
  (конфиг `elk_config` и страница `/journal-help-action`).
- PDF-инструкции в исходной папке — сканы без читаемого текста, поэтому шаги
  онлайн-урока и питания составлены по описанию из ТЗ и требуют сверки на
  живом интерфейсе.

## Проверка перед релизом

- `node --check` для `data.js`, `popup.js`, `content.js`.
- Симуляция поиска: все типовые запросы находят нужный маршрут.
- Симуляция подсветки: слово «ПФДО» подсвечивается, при отсутствии слова — 0 совпадений.
